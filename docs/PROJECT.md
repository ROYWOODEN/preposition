# Predlog

Telegram-бот для приёма и модерации постов одного канала. Обработчики работают через grammY и long polling. Данные и очередь уведомлений хранятся в SQLite.

## Права

- Владелец задаётся через `OWNER_TELEGRAM_ID`. Только он назначает и снимает главных модераторов.
- Главный модератор управляет настройками, шаблонами, причинами отклонения, блокировками обычных пользователей, очередью публикаций и командой обычных модераторов. Ему доступны полная история и статистика. Администраторы не могут менять свои права. Главный модератор не может снимать или блокировать владельца и других главных модераторов.
- Обычный модератор обрабатывает заявки и просматривает свою историю.

Чтобы назначить главного модератора, владелец сначала добавляет человека как обычного модератора, затем выбирает «Повысить» в разделе «Управление → Команда». «Убрать» снимает роль целиком. Приглашение обычного модератора подтверждает его создатель или владелец. Если создатель утратил права, запрос направляется владельцу. Ранее созданные приглашения остаются у владельца.

## Обновление базы

Миграция 0003 добавляет два поля в существующие таблицы. Роль всех действующих модераторов по умолчанию остаётся обычной. Для деплоя включите SQL и файлы метаданных из `migrations/`.

Команда запуска в Dockerfile и локальная команда `npm run dev` передают `--migrate` и применяют доступные миграции перед подключением к Telegram. В Docker команда проверяет доступ пользователя `node` к `/app/data` уже после подключения тома, при необходимости настраивает права каталога и запускает бота от `node`. Если хостинг переопределяет команду на `npm start` или `node dist/main.js`, выполните `npm run db:migrate` после остановки старого экземпляра либо добавьте `--migrate` в команду запуска. Используйте прежний постоянный том с базой и сделайте резервную копию командой `npm run db:backup` перед обновлением.

## Меню и черновики

В команде сначала отображается владелец, затем отдельные группы главных и обычных модераторов. Карточки из списков возвращаются на исходную страницу, включая историю. Разделы управления ведут обратно в «Управление».

Кнопка «Предложить пост» открывает подсказку. Строка черновика создаётся при получении текста или вложения. Старые пустые черновики скрыты и не занимают лимит. При удалении последнего вложения черновик без текста отменяется.
